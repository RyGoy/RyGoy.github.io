---
title: "Commentary"
description: "Notes by older students pointing out connections between posts and articles."
---

Older students write commentary to point out connections between posts and articles for newer students. Each note lists the pages it ties together, and those pages show it in their **Commentary** panel when commentary is turned on in the sidebar.

**To add commentary**, use the *Add commentary* link on any post or article, or the one below, and write your note: a title, then the connection, with the link of every page it ties together. A moderator reads every note before it appears here.

Every note is a Markdown file in `content/commentary/`, so that folder can also be opened as an Obsidian vault: `connects` is a list of site links, and `[[Note title]]` links to another note.
